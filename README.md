# 🚖 Uber Trip Analysis Dashboard

## 📌 Project Overview

This project analyzes Uber trip booking data using Power BI to uncover booking patterns, customer behavior, trip trends, vehicle performance, and location insights.

The dashboard provides interactive visualizations that help understand how bookings vary across time, vehicle types, payment methods, locations, and trip distances.

---

## 🎯 Business Objective

The goal of this project is to transform raw Uber trip data into actionable business insights by:

- Tracking booking trends
- Analyzing trip demand patterns
- Evaluating vehicle performance
- Understanding customer booking behavior
- Identifying popular pickup and drop-off locations
- Monitoring revenue and trip metrics

## 📊 Dashboard Pages

### 1. Overview Analysis

Provides a high-level summary of Uber operations.

#### Key KPIs

- Total Bookings
- Total Booking Value
- Average Booking Value
- Total Trip Distance
- Average Trip Distance
- Average Trip Time

#### Analysis Included

- Booking trends by day
- Vehicle performance analysis
- Payment method analysis
- Day vs Night trip analysis
- Location analysis
- Most preferred vehicle types

---

### 2. Time Analysis

Analyzes booking behavior over time.

#### Analysis Included

- Total bookings by pickup time
- Booking trends by hour
- Booking trends by weekday
- Peak booking hours
- Heatmap of bookings by hour and day

---

### 3. Detailed Analysis

Provides transaction-level booking information.

#### Details Included

- Trip ID
- Pickup Date
- Pickup Time
- Vehicle Type
- Payment Type
- Passenger Count
- Trip Distance
- Booking Value
- Pickup Location
- Drop-off Location

This page enables detailed exploration and filtering of trip records.

---

## 📈 Key Insights

- UberX generated the highest number of bookings.
- Afternoon and evening hours recorded the highest trip demand.
- Cash and Uber Pay were the most commonly used payment methods.
- Certain pickup locations consistently generated higher booking volumes.
- Weekend bookings were higher compared to weekdays.
- Day trips accounted for a larger share of total trip distance than night trips.
